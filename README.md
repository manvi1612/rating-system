# Rating System

A React application with a star rating system and dialog box created for SD-260 Assignment 2.

## Features

- Star rating system using Font Awesome icons
- Dynamic star selection using map()
- Rating text display
- Dialog/modal box with image
- Open and close dialog functionality
- Functional components
- React `useState` hook
- Props used between parent and child components


## Technologies Used

- React
- JavaScript
- CSS
- Font Awesome Icons


## Components

### Star Component
Displays individual star icons and handles click events.

### StarRating Component
Contains five stars dynamically rendered using `map()` and displays rating messages.

### Dialog Component
Displays a modal dialog with an image and close button.
